# 제타 현재 채팅 프로필

제타 웹 채팅방에서 선택된 유저 프로필과 등장인물의 사진, 이름, 소개 본문을 한 창에서 확인하는 Tampermonkey 유저스크립트입니다.

## 설치

1. 브라우저에서 Tampermonkey를 설치하고 활성화합니다.
2. [설치용 스크립트 열기](https://raw.githubusercontent.com/casualJH/zeta-current-profiles/main/zeta-current-profiles.user.js)를 누르고 설치합니다.
3. 이전 버전이 별도로 활성화돼 있다면 끄고 제타 채팅방을 새로고침합니다.

## 사용 방법

1. 채팅방의 **프로필** 버튼을 눌러 창을 엽니다.
2. 유저 프로필 아래에서 등장인물별 카드를 확인합니다. 캐릭터 소개가 비어 있으면 채팅에서 해당 캐릭터의 **프로필 사진**을 누릅니다.
3. 긴 본문은 처음 세 줄이 표시됩니다. 카드의 **+ 더보기** 또는 창 상단의 **모두 펼치기**로 전체를 확인할 수 있습니다.
4. 제목줄을 드래그해 창을 옮기고, 오른쪽 아래의 작은 삼각형을 드래그해 크기를 조절합니다.

플롯 상세 응답에 등장인물 소개가 포함되면 캐릭터 ID를 기준으로 각 카드에 연결합니다. 사용할 수 있는 소개는 플롯에 따라 달라집니다.

창 아래 **진단** 메뉴에서 수집 상태를 확인할 수 있습니다. **프로필 JSON 보기**에는 수집한 본문과 이미지 주소가 포함되므로 공유하기 전에 내용을 확인하세요.
